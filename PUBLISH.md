# Publishing this course to GitHub

1. Create a new repo under github.com/vibe-coding-course (e.g. `web-app-course`), public, no README.
2. Upload this whole folder (drag and drop on GitHub's "uploading an existing file" page), or ask your coding agent:
   "Initialize git in this folder, commit everything with the message 'Course v1', and push to <repo URL>."
3. In the repo's Settings, tick **Template repository** so students can click "Use this template".
4. Optional: Settings → Pages → deploy from `main` to get a free course website.
5. Later: import `modules/*.md` into the LetsVibeAI e-learning pages (one lesson per page).
