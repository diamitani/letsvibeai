# Capstone — Build and demo a revenue-ready app

Students ship one live web app with sign-in, a database, a paid plan and an AI agent, then demo it in five minutes. Passing earns the LetsVibeAI certificate.

**Deliverables:**

- [ ] `/context` pack (Module 6) and all 11 docs in `/docs` (Module 8)
- [ ] Architecture diagram with all 11 building blocks mapped to tools (Module 4)
- [ ] One agent with its `/agent` folder, at least one skill and one tool (Module 7)
- [ ] GitHub repo with a clean commit history (Module 10)
- [ ] Live production URL passing the pre-launch checklist (Module 10)
- [ ] 5-minute demo: the problem, the user, a live walkthrough, the architecture, what's next

**Rubric (100 points):** works end to end (30) · architecture is sound and secure (25) · documents are complete and consistent (20) · design and UX (15) · demo clarity (10).

**Capstone ideas:** an AI tutor for one subject, a niche directory with AI search, a client portal for a service business, a voice-agent booking app, a marketplace for local creators.
