# Module 4 — GitHub Two-Way Sync & Cursor / Windsurf Polish

The optimal vibe coding workflow pairs rapid web scaffolding in Lovable with deep code refactoring in Cursor or Windsurf.

### Lesson 4.1 — Two-Way Repository Synchronization

- Push initial scaffold from Lovable to GitHub (`main` or `feature/v1`).
- Clone locally and open in Cursor with `.cursorrules` configured.
- Use Cursor Composer (`Cmd+I`) to add complex business logic, perform performance optimizations, and fix edge cases.
- Commit and push back to GitHub; Lovable automatically pulls the updates.
