## Phase 3: Bundle Assets for Development

### Product Requirements Document (PRD)

- Project overview and goals
- Target users and use cases
- Feature requirements (MVP scope)
- Technical constraints and preferences
- Success metrics

### Phase 4: Build and Deploy Your Application

This is where the assistant gets a "body" — a user interface. Use an AI coding assistant to generate the UI.

### Practice Prompt: Chat Interface Builder

> Generate HTML and CSS for a simple web chat interface:
> 1. Main container with dark theme
> 2. Chat window with lighter background for messages
> 3. Message list showing 'User' and 'Assistant' messages
> 4. Input area at bottom with text field and 'Send' button
>
> Make it clean and modern. Only HTML and a <style> tag, no JavaScript.
