# Glossary

| Term | Definition |
| --- | --- |
| Agent | An AI model working in a loop with instructions, tools and memory toward a goal |
| Agent harness | Everything around the model that turns it into a worker: instructions, tools, memory, loop, guardrails |
| Agent runtime | The process that executes an agent's loop and tool calls |
| Agent control panel | The dashboard where people monitor and approve agents |
| AI gateway | One connection that routes to many model providers |
| API | A doorway for one program to request things from another |
| ADK | Agent development kit — an SDK for building agents |
| Chain prompting | Feeding one prompt's output into the next to refine results |
| Cloud hosting | Running your app on rented, always-on computers |
| Compute instance | One rented virtual computer in the cloud |
| Context engineering | Designing everything the model sees: instructions, docs, examples, memory |
| Context window | How many tokens a model can consider at once |
| Git versioning | Saving every change as a commit so you can review or undo it |
| GPU | A chip that does thousands of calculations in parallel; powers AI |
| Hallucination | A confident, made-up answer caused by missing facts |
| LLM | Large language model — a neural network trained to predict the next token |
| MCP | Model Context Protocol — an open standard for connecting tools to agents |
| Model provider | A company serving AI models by API |
| Sandbox | An isolated environment where agents run code safely |
| SDK | Software development kit — ready-made code for using a service |
| Skill | A reusable, step-by-step process an agent can apply |
| Token | A chunk of text (\~¾ of a word) — the unit AI reads, writes and bills |
| VPS | Virtual private server — a flat-price rented server |
