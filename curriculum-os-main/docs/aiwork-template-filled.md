## ❓ FAQ Section

### 1. **How long does setup take?**
**Answer:** Under 5 minutes. Clone the repo, run `./start.sh`, and open `http://localhost:3002`. No complex configuration required. If you have a DeepSeek API key, add it via `export DEEPSEEK_API_KEY="sk-..."` for LLM-powered features. Without it, the system runs in simulated mode with structured default curricula.

---

### 2. **What makes CurriculumOS different from other AI learning tools?**
**Answer:** CurriculumOS is built on the **ROSTR framework** — a production-grade multi-agent architecture with:
- **PAL (Prompt Abstraction Layer):** Intent compilation instead of raw prompting
- **RAG DAL:** 3-tier credibility scoring with multi-pass retrieval
- **NPAO:** 5D phase classification + 4D priority allocation
- **Persistent State:** Knowledge compounding across sessions

Most tools use single-shot LLM calls. CurriculumOS orchestrates specialized agents with phase-aware routing and credibility-weighted knowledge retrieval.

---

### 3. **Is my curriculum data secure?**
**Answer:** Yes. CurriculumOS runs locally on your machine or private Vercel deployment. Your learning goals, research queries, and generated curricula never leave your infrastructure unless you explicitly integrate external APIs (like DeepSeek). The ROSTR Hub state management uses file-based storage with namespace isolation — no external data sharing by default.

---

### 4. **Can I test it before committing?**
**Answer:** Absolutely. CurriculumOS works in **simulated mode** without any API keys. Clone the repo and run `./start.sh` to test the full pipeline with structured default curricula. When you're ready for LLM-powered features, add a DeepSeek API key. We also offer a 14-day free trial for Growth and Pro plans.

---

### 6. **Can I customize the curriculum generation logic?**
**Answer:** Yes. CurriculumOS is fully open-source (MIT license). You can:

- Adjust PAL compilation rules
- Change RAG DAL credibility tiers and weights
- Customize NPAO priority scoring formulas
- Add new phases to the 5D taxonomy (PreD → Design → Dev → Deploy → Debug)

For enterprise users, we offer custom agent development and dedicated ROSTR framework training.
