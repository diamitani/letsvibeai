Modes

Chat vs. Cowork vs. Code

Three distinct modes in the Claude Desktop App. Pick the right one for the job.

Feature Chat Cowork Code (CLI)
PurposeQ&A, brainstorming, one-off draftsMulti-step tasks on your files & appsAgentic coding in the terminal
File accessUpload to conversation onlyDirect access to a local folderFull codebase via terminal
SkillsNoYes — full skill libraryYes — via SKILL.md files
Scheduled tasksNoYesVia cron/hooks
ConnectorsNoYes — Slack, Calendar, Asana, etc.Via MCP servers
ArtifactsYesYesNo (file output)
Best for at AtlasEveryone — daily driverMarketing, Sales, RevOps, OpsEngineering, DevOps

Rule of thumb: Use Chat for quick questions. Switch to Cowork when you need Claude to create files, process data, or run multi-step workflows and come back with finished output.

Setup

Getting Started — Onboarding Checklist

Complete these steps to get fully set up with Claude at Atlas.

Week 1 — Foundation

  • Download the Claude Desktop App from claude.com/download
  • Set Global Instructions — Settings → Cowork → Global Instructions. Include your name, role, team, and output preferences.
  • Create your first Project — pick a local working folder, add project-specific instructions.
  • Verify the 21 Atlas skills are installed in your .claude/skills/ directory.
  • Connect at least one tool — Calendar, Slack, Asana, or Outlook via Settings → Connectors.
  • Complete one real task in Cowork — a report, email draft, presentation, or data analysis.

Month 1 — Expansion

  • Build 2-3 role-specific skills using the skill-creator skill.
  • Set up a scheduled task — weekly competitive brief, daily pipeline snapshot, etc.
  • Create an Artifact — interactive dashboard, HTML template, or calculator.
  • Share a skill with a teammate. Skills are just files — drop them in a shared folder or GitHub repo.
  • Add context files to your project folder — ICPs, messaging docs, brand guidelines, templates.
  • Combine skills for complex tasks — brand guidelines + presentations for a branded deck, etc.

Need help? Ask Claude: "create a new skill for [your task]" or "help me set up a project for [your workstream]" and it walks you through it.

Best Practices

10 Practices That Make Claude Better

Proven patterns from our rollout — adopt these and your outputs improve immediately.

1. Be specific, not vague

"Write a 200-word LinkedIn post about EOR compliance in Germany targeting HR Directors" beats "write a LinkedIn post."

2. Use Projects — always

Never work in a bare conversation. Create a project with context files and instructions for every workstream.

3. Front-load context

Drop brand docs, ICPs, past examples, and reference materials into your project folder before asking for outputs.

4. Iterate, don't restart

If the first output is 80% right, fix the 20%. Don't start a new conversation — Claude has full context.

5. Give feedback to build memory

Say "that was perfect" or "never do X again." Claude remembers and improves over time.

6. Use scheduled tasks

Weekly competitive briefs, daily pipeline summaries, monthly reports — set them once, get them forever.

7. Combine skills

"Use brand guidelines AND the presentation skill" produces better results than either alone.

8. Chat for quick things

Don't burn Cowork tokens on simple questions. Chat mode is faster and cheaper for brainstorming and Q&A.

9. Review before sharing

Always check output for accuracy, brand compliance, and confidential data before sending externally.

10. Share skills with your team

Build a skill that works well? Drop the file in the shared repo so everyone benefits from the same quality bar.

Security & Data Handling

Never share PII, client contracts, credentials, or confidential strategy docs with Claude. If you wouldn't email it to an external consultant, don't share it. Use Team/Enterprise plans for admin controls. Review all outputs before external sharing.
