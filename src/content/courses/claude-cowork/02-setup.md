## Four setup steps

1. **Install the Claude desktop app.**
2. **Tell Claude about you** in your instructions.
3. **Connect a work folder.**
4. **Check your memory settings.**

## Write your instructions

Your instructions apply to every conversation. Include:

- **Who you are** and who you write for
- **How you like things written** (tone, length, style)
- **The formats you want back** (doc, bullet summary, table)

## Connect a work folder

- Claude can only see the folders **you** connect.
- It runs code in a separate, isolated sandbox.
- It asks your permission before deleting anything.

## Use memory

- Say *"Remember that our launch is November 12th"* and it sticks.
- Say *"Forget the old positioning doc"* and it's gone.
- You can view, edit or pause memory any time in **Settings**.

## Recap

Instructions, folders and memory mean every task starts already briefed.

> **Your mission:** install the app, write your instructions, and connect one work folder.
