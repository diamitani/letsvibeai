## What's inside a plugin

- **Skills** that teach Claude a workflow
- **Connectors** to your outside tools
- **Agents:** specialists Claude can delegate to
- **Hooks:** small scripts that run at set moments

## Install one in a minute

1. Open **Customize** in the sidebar and choose **Plugins**.
2. Browse **Discover**, pick one and click **Install**.
3. Open its **Connectors** tab and connect each tool.

## There's a plugin for most roles

- **Business teams:** sales, marketing, legal
- **Technical teams:** data, engineering, design

Install the one that matches your job and you start with a team's worth of know-how.

## Plugins at team scale

- Admins can **require** a plugin so everyone has it.
- Teams can share their own plugins from a **Git repository**.
- Only install plugins from **sources you trust**.

## Recap

A plugin bundles skills, connectors and agents into one install for your role.
