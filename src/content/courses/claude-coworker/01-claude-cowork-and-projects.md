# Module 1 — Claude Projects & Cowork Architecture

Claude Projects turn Claude from a fleeting chat window into a persistent organizational coworker with project-specific knowledge bases, customized instructions, and shared team memory.

### Lesson 1.1 — Context Engineering with Custom Instructions

- Setting up project system prompts that define your brand voice, coding conventions, and architectural guardrails.
- Pinning documentation files: PRDs, API schemas, design tokens, and database schemas.
- Using Cowork mode to pair-program across multiple browser tabs and terminal windows.
