# Module 5 — Team Governance & The One Must Act Theorem

Enterprise agent adoption requires strict governance, prompt review standards, and compliance gates.

### Lesson 5.1 — The One Must Act Principle in Enterprise

- Every AI-generated commit must have an attributed human owner or verified test harness.
- Calibrated Truth Guards: Creative warmth in marketing copy, strict operational data rigor in backend transactions.
- Zero credential exposure in chat transcripts or agent prompt histories.
- Continuous evaluation and benchmark tracking across agent versions.
