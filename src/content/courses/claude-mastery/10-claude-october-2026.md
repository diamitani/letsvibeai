## Three ways to work, side by side.

Claude now works three ways, side by side. Chat, to think and draft. Agentic tasks, formerly Cowork, to get multi-step work done across your files and apps. And Claude Code, to build software. And you no longer pick a mode first. Claude moves between them.

- **Chat** — Think — Q&A, brainstorms, drafts
- **Agentic tasks** — Get work done — files, apps, finished output
- **Claude Code** — Build software — terminal, web, desktop

## Four blocks. One system.

Four building blocks make it stick. Projects. One workspace per workstream. Memory. One shared memory across chat and agentic tasks. Skills. Your way of working, loaded automatically. And artifacts. Live pages, dashboards, and tools you can share.

- **Projects** — One workspace per workstream
- **Memory** — Shared across chat and tasks
- **Skills** — Your way, loaded automatically
- **Artifacts** — Live pages you can share

## Let it run on a schedule.

Then automate the recurring work. Routines run in the cloud, even with your laptop closed. Scheduled tasks run on your computer, through the app. And /loop keeps watching a build or a pull request, inside a Claude Code session.

| Name | Value | Note |
| --- | --- | --- |
| Routines | `Anthropic's cloud — laptop off is fine` |  |
| Scheduled tasks | `Your computer — via the app` |  |
| /loop | `Inside a Claude Code session` |  |

## “Every Monday at 8am, build a competitive brief.”

Ask once. Claude sets up the schedule.

And you set it up in plain English. Every Monday at eight, build a competitive brief, and save it to this project.

## Pick the model by the job.

Finally, pick the model by the job. Haiku, for speed and volume. Sonnet, as your everyday driver. Opus, for heavy, judgment driven work. And Fable, for the problems Opus can't crack.

- **Haiku 5.5** — Fast, low-cost, high-volume
- **Sonnet 5.5** — Everyday docs, slides and sheets
- **Opus 5.5** — Judgment-heavy, long-running work
- **Fable 5.1** — Hardest reasoning, long-horizon agents

## What you just learned.
