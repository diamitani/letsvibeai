# Module 1 — Lovable & Bolt: Prompt to Full-Stack Application

Lovable and Bolt have transformed modern vibe coding by eliminating initial boilerplate setup. In a single natural language description, you scaffold complete multi-page web applications with modern design systems, working routing, and component states.

### Lesson 1.1 — The Rapid Prototyping Flywheel

- **Describe the Core Value**: Start with the primary user flow (e.g. "A real estate directory with interactive search, price filter pills, and bookmarking").
- **Iterative Visual Refinement**: Select components directly in the canvas and prompt for exact visual adjustments without touching code editors.
- **Exporting to GitHub**: Connect your Lovable or Bolt project to a public or private GitHub repository for version control and team collaboration.
