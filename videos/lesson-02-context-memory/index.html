# Project Rules
Stack: Next.js 15, TypeScript, TailwindCSS, Supabase

## Always
- Run `pnpm test` and `pnpm lint` before marking tasks complete
- Follow atomic git commits with semantic messages

## Never
- Never edit files in `/dist` directly
- Never commit `.env` or plaintext API keys
