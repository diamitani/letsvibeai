Prompts That Survive Production

Structure beats clever wording. Transform informal conversational prompts into robust engineering specs.

The Anatomy

5 Parts of a Durable Prompt

PART 01
Role
Who the agent is and its exact domain perspective.
PART 02
Goal
Clear, unambiguous definition of success.
PART 03
Constraints
Inviolable limits, length, tech stack, and tone rules.
PART 04
Examples
Concrete references: show, do not just tell.
PART 05
Output
Exact format: JSON, markdown table, or code diff.
Execution Brief

Read It Like a Lead's Specification

task-brief.md
Role: Principal Frontend Architect
Goal: Refactor the Stripe webhook handler with idempotent upserts
Constraints: Zero downtime, use Postgres RLS, no client secrets
Example: See `docs/16-payments.md` and `src/core/webhooks.ts`
Output Format: Implementation code + vitest regression test suite

Execution Mindset

Iterate. Do Not Restart.

When an agent misses, say exactly what is wrong and what to keep.
Starting a new chat wipes away all learned context, file indexing, and dependency awareness. Targeted steering produces accurate results in a fraction of the time.
Summary

The 4-Step Production Loop

1. Plan
Ask for step breakdown.
2. Correct
Refine before coding.
3. Execute
Run one atomic step.
4. Verify
Test against constraints.
