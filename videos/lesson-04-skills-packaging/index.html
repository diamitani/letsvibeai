Skills: Package Your Expertise

Teach the agent a job once. If you have explained a process three times, package it as an auto-triggering skill.

The Definition

A Skill Teaches One Job, Your Way

A skill is a self-contained directory with a single SKILL.md file inside.
When a user prompt matches the description triggers, the agent automatically loads the full instructions, tool requirements, and step-by-step checklists into context.
Anatomy

Name. Description. Steps.

skills/stripe-payments/SKILL.md
---
name: stripe-payments
description: Create PCI-compliant Stripe checkout sessions & webhooks. Use when asked for billing, checkout, or subscriptions.
---

# Execution Steps
1. Generate server-side Checkout Session with client_reference_id
2. Implement webhook signature verification handler
3. Upsert user entitlement idempotently in Postgres
Scale & Efficiency

Progressive Disclosure

1
Fast Indexing
Only the name and description load into agent memory at boot time.
2
On-Demand Body
The full procedural instructions load only when a matching task occurs.
3
Modular Docs
Large schemas, API references, and templates live in separate files.
