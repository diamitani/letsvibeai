Connectors & Model Context Protocol

Connect, don't copy-paste. Give your agent direct access to real databases, tools, APIs, and repositories.

The Rule

Connect. Do Not Paste.

Pasting static data into chats goes stale the second you hit send.
An MCP connector gives the agent live query access to fetch fresh database schemas, inspect active issue trackers, query GitHub PRs, and invoke remote cloud actions securely.

Security

Grant the Least Access That Works

01
Read-Only First
Start by giving the agent read and query access before granting write capabilities.
02
Scoped Tokens
Pass credentials through environment variables. Never write raw tokens in config files.
03
Approval Gates
Require human approval for mutating actions like DB migrations, payments, and emails.
