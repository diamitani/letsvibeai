Commands, Prompts & Workflows

Stop typing the same prompt every day. Convert repeat requests into instant, parameterized slash commands.

The Rule

Pasting the Same Prompt? Make It a Command.

Type a slash and a word, and your entire prompt chain executes instantly.
Commands turn multi-step tasks like code review, test generation, schema migrations, and branch deployments into reusable, team-shared shortcuts.
Example

/review in Six Lines of Code

.claude/commands/review.md
---
description: Review staged changes for security and logic bugs
argument-hint: [focus area]
---

Review `git diff --staged`.
Focus on: $ARGUMENTS
List security vulnerabilities first, then style nits.

Collaboration

Keep Commands Directly in Git

1. Write Once
Create one clean markdown file per command.
2. Commit
Commit to version control next to source code.
3. Instant Sync
Every engineer gets the command on their next pull.
