Agents & Subagents: Plan, Build, Ship

Delegate like an engineering lead, not a typist. Split complex features across specialized, isolated subagent swarms.

The Problem & Solution

Split Big Work Across Specialists

🔍
Researcher
Scans docs, gathers API patterns, investigates dependencies.
⚡
Builder
Implements atomic modules in a clean, uncluttered context.
🛡️
Reviewer
Audits diffs for security holes, types, and logic errors.
🧪
QA & Tester
Runs unit tests, integration suites, and contract audits.

You are a strict, adversarial code reviewer.
Report issues grouped by severity (Critical, Warning, Nit).
Never edit files directly — return actionable findings only.
Delegation

A Delegation Brief That Works

1. The Goal & Why
Clear objective and user-facing rationale.
2. Definition of Done
Unambiguous acceptance criteria.
3. What NOT to Touch
Protected files, schemas, and API contracts.
4. Report Back Format
Structured summary and test pass rates.
Delivery Cycle

Plan. Build. Test. Ship.

1. Plan
Lead agent architects and approves steps.
2. Build
Subagents code modules in parallel.
3. Test
Automated reviews and verification pass.
4. Ship
Commit to git and deploy to production.
Mindset

You Lead. Agents Build. You Review.
