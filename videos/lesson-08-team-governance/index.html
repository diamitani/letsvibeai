Governance for Teams

Make it safe, then make it stick. Implement security guardrails, audit logging, and team-wide skill libraries.

The Doctrine

Two Sets of Rules

1. Rules for the Agents
Written in CLAUDE.md and AGENTS.md. Scoped tool allowlists, read-only defaults, and automated test gates.
2. Rules for the Humans
Written in team playbooks. What data may be processed, code review requirements, and approval processes for live mutations.
Data Boundaries

Protect What Matters

01
No Secrets in Prompts
Never paste private API keys, customer PII, or credentials directly into prompts.
02
Approved Connectors
Maintain a vetted registry of authorized MCP servers and data sources.
03
Immutable Audit Logs
Track every tool execution, file modification, and prompt session in git history.
