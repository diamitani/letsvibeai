Module 01: Foundations

What is Vibe Coding?

Building production software by describing intent in natural language while AI coding agents handle translation and execution.

Your New Role

The Film Director 🎬

You hold the vision, dictate the requirements, inspect the architecture, and steer the process. You are the architect of intent.

The Agent's Role

The Expert Typist ⚡

The agent writes the syntax, resolves imports, generates tests, and manages boilerplate at superhuman speed.

Principle 01

Direction Beats Guessing

LLMs are pattern completion engines. When prompts are ambiguous, they hallucinate. When directed with constraints, they compile precision.

❌ Vague (Invites Guessing)
"Make me a login page"
⚠️ Result: Random mock UI, missing Supabase connection, no error states, non-responsive form fields.
✅ Directed (Routes to Answer)
"Build Supabase OAuth + Magic Link"
✨ Result: Next.js App Router, SSR cookie handling, Google OAuth + Magic Link, redirects to /dashboard with inline errors.
Principle 02

Every App Has an Architecture

01 · FRONTEND

Experience Layer

What users see and touch: Next.js, Tailwind CSS, Lucide icons, responsive chat UIs.

02 · BACKEND

API & Logic

Server Actions, route handlers, background cron jobs, and business logic execution.

03 · DATABASE

Postgres & RLS

The single source of truth for users, workspaces, records, and Row-Level Security policies.

04 · AUTHENTICATION

Identity & Access

OAuth (Google, GitHub), magic links, session cookies, and multi-tenant permission gates.

05 · COMMERCE

Stripe Payments

Checkout sessions, webhooks as source of truth, customer portal, and tiered entitlements.

06 · AGENTS & MCP

AI Worker Swarm

Harness, isolated skills, Model Context Protocol connectors, and automated feedback loops.
