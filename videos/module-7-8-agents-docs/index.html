The Agent Folder Anatomy

tree /agent -L 2
/agent
├── /instructions # Persona, rules, bounds
├── /agents # Main agent entrypoints
├── /sub-agents # Delegated specialists
├── /skills # Step-by-step recipes (SKILL.md)
├── /tools # MCP servers, APIs, connectors
├── /memory # Past session context & state
└── /harness # Loop orchestration engine
